## 1. 目标

在现有人物卡同步能力上补齐 RPBox 平台内的二次创作能力，不再只做 TRP3 数据镜像。

- 支持平台内直接编辑人物卡
- 增加 RPBox 专属字段与名片式展示信息
- 支持人物卡配图、封面或补充视觉素材
- 为帖子嵌入与公开展示复用统一的人物卡卡片能力

---

## 2. 验收标准

完整产品需求、数据边界与接口约定见 `docs/人物卡管理功能需求.md`。

- [x] 人物卡数据模型明确区分 TRP3 原生字段与 RPBox 扩展字段
- [x] 编辑页支持名片摘要、扩展字段、配图等平台内二次编辑
- [x] 详情页提供更像名片的展示区，同时保留 TRP3 字段查看能力
- [x] 扩展字段的同步与写回边界清晰，不破坏现有 TRP3 兼容性；版本历史明确列为后续范围
- [x] 为帖子嵌入、公开个人中心展示提供统一卡片 DTO / API
