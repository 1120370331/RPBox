## 1. 目标

在现有人物卡同步能力上补齐 RPBox 平台内的二次创作能力，不再只做 TRP3 数据镜像。

- 支持平台内直接编辑人物卡
- 增加 RPBox 专属字段与名片式展示信息
- 支持人物卡配图、封面或补充视觉素材
- 为帖子嵌入与公开展示复用统一的人物卡卡片能力

---

## 2. 验收标准

- [ ] 人物卡数据模型明确区分 TRP3 原生字段与 RPBox 扩展字段
- [ ] 编辑页支持名片摘要、扩展字段、配图等平台内二次编辑
- [ ] 详情页提供更像名片的展示区，同时保留 TRP3 字段查看能力
- [ ] 扩展字段的同步、版本历史与写回策略清晰，不破坏现有 TRP3 兼容性
- [ ] 为帖子嵌入、公开个人中心展示预留统一卡片 DTO / API
