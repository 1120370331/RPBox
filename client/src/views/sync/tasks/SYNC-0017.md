# SYNC-0017: 人物卡公开审核、多图与 TRP3 安全写回

## 1. 目标

把人物卡从可编辑的展示资产升级为可安全发布、可多图陈列、可回写 TRP3 且能够恢复的完整工作流。

## 2. 验收标准

- [x] 人物卡中的可编辑颜色字段均提供取色器和精确 HEX 输入，二者双向同步并校验。
- [x] TRP3 `CH` 作为职业/人物名称颜色双向承接；编辑预览、详情、展示墙和帖子悬浮卡中的人物名使用该颜色。
- [x] 设置为“已发布 + 公开”后进入版主审核；审核通过前游客不可见，所有者能看到明显的待审/驳回状态。
- [x] 版主中心可以查看人物卡待审内容并通过或驳回；公开卡修改时不得泄漏未审核版本。
- [x] 角色大图支持多张、有序陈列、封面切换和删除，并兼容旧单图人物卡。
- [x] RPBox 人物卡可以转换为 TRP3 profile；既支持写回来源 profile，也支持空白人物卡创建新的 profile。
- [x] 写回前显示危险确认并强制备份当前版本；回退前再次保护当前版本。
- [x] TRP3 账号备份和本地写回历史可以查看、命名、回退和删除；默认档名包含时间和内容哈希。
- [x] 所有版本、图片和审核接口均校验所有权/版主权限，图片权限与审核快照一致。
- [x] 前端、Rust 与 Go 定向测试及正式构建通过，独立验收结论为 PASS。

## 3. 兼容边界

- `name_color` 继续兼容旧客户端和旧数据，但不得与新的 `class_color` 产生两个不同的 TRP3 `CH` 值。
- 旧 `portrait_image_url` 继续作为封面别名；新客户端以 `portraits` 画廊为准。
- RPBox 专属大图、摘要和富文本不写入 TRP3；只转换双方共用的基础信息。
- 首次公开待审时不产生公开数据；已经通过审核的公开卡在修改待审期间继续展示最后一次通过的快照。
