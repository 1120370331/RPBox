## 1. 目标

重做社区广场的信息结构，把现在的活动日历改成更直观的 Banner 区，并把帖子流与活动流分开。

- 社区首页不再默认以日历承载活动
- 社区广场支持帖子 / 活动双 tab
- 让活动内容有更强的视觉曝光位

---

## 2. 验收标准

- [ ] 社区广场首屏改为活动 Banner 区，不再默认展示月历
- [ ] 新增帖子 / 活动双 tab，帖子 tab 只展示帖子，活动 tab 只展示活动
- [ ] 活动 Banner 展示主视觉、时间、地点、类型与跳转入口
- [ ] 搜索、筛选、公会过滤、置顶信息在双 tab 模式下行为清晰
- [ ] 空状态、分页和加载态适配新的广场结构
