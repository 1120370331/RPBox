# COMM-0003: 桌面端帖子转发能力补齐

| 属性 | 值 |

| 优先级 | P2 |
| 状态 | DONE |

| 依赖 | - |

---

## 1. 目标

补齐桌面端当前缺失的帖子转发能力，与移动端的分享体验至少保持同级。

- 桌面端帖子详情和列表卡片提供分享入口
- 分享内容包含帖子标题、纯文本摘要和公开访问链接
- 不支持系统分享时依次降级到 Clipboard API 和 DOM copy

---

## 2. 验收标准

- [x] 桌面端帖子详情提供明确的转发 / 分享入口
- [x] Tauri 环境可调用系统分享或复制链接能力
- [x] 分享内容包含帖子标题、访问链接和纯文本摘要
- [x] 成功 / 失败提示使用现有 Toast 和双语文案
- [x] Web 或不支持的运行环境有明确降级方案

## 3. 实施记录

- 新增 `shareRouteLink`、公开帖子 URL 和纯文本摘要工具。
- 列表分享按钮阻止卡片点击冒泡，不触发帖子导航。
- `share.test.ts` 覆盖 7 项工具行为，`communityShare.test.ts` 覆盖 3 项组件行为。
- 最终验证：客户端 16 个测试文件、56 项测试通过，生产构建通过。
