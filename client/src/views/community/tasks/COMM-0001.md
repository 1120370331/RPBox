## 1. 目标

支持在社区帖子中插入人物卡卡片，让人物设定可以直接参与内容创作与传播。

- 编辑器内可选择人物卡插入
- 预览、详情和正文渲染统一展示
- 点击人物卡卡片可继续查看对应人物资料

---

## 2. 验收标准

完整产品需求、失效降级与 Hover/Focus 交互约定见 `docs/人物卡管理功能需求.md`。

- [x] 帖子编辑器支持选择自己已发布且公开的人物卡并插入卡片
- [x] 帖子预览、详情、编辑回填对人物卡卡片渲染一致
- [x] 人物卡卡片在重新鉴权后展示头像、名片摘要和必要配图信息
- [x] 私密或失效人物卡在公开帖子中的引用有权限校验与降级态
- [x] 卡片点击后可跳转到人物卡详情或公开展示页
