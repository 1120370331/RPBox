# SRV-0006: 帖子编辑审核去重与终态收敛

| 属性 | 值 |
|------|-----|
| ID | SRV-0006 |
| 类型 | FIX |
| 优先级 | P0 |
| 状态 | DONE |
| 模块 | server/internal/api/post.go, server/internal/api/moderator.go, server/internal/api/admin.go |
| 依赖 | - |

---

## 1. 目标

修复帖子被连续编辑并触发审核时，审核区残留旧记录的问题，确保版主看到的始终是最终一次待审核内容。

- 同一帖子只保留一个有效编辑审核槽位
- 连续编辑应覆盖旧待审内容，而不是留下陈旧审核项
- 审核列表和统计角标都应与最终状态一致
- 兼容旧数据中原帖已删除但编辑审核仍残留的孤儿记录，避免审核卡死

---

## 2. 验收标准

- [x] 同一 `post_id` 在帖子编辑审核流程中只有一个有效待审核记录
- [x] 连续编辑会覆盖旧的待审核内容，不再在审核区残留旧项
- [x] 审核中心列表、统计角标和快速审核都只基于最终一次待审核内容
- [x] 已拒绝或已通过的历史策略明确，且不会再次作为待审核旧项出现
- [x] 为连续编辑覆盖场景补充服务端回归测试
- [x] 原帖已删除的旧编辑审核会被隐藏并可自愈清理
