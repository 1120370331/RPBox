# RPBox 成就勋章总图生成 Prompt

## 总 Prompt

Create a single transparent-background sprite sheet for RPBox achievement medals. The sheet must be exactly 5 columns by 5 rows, 25 medals total. Each cell is 512 x 512 px, full canvas is 2560 x 2560 px, no gutters, no text, no numbers, no watermark. Keep every medal centered in its own cell with at least 48 px safe padding, consistent front-facing view, consistent scale, clean silhouettes for easy slicing.

Art direction: fantasy roleplay community, elegant Azeroth-inspired parchment and enchanted metal, premium game achievement icons, soft painterly 3D relief, readable at 64 px, high contrast center symbol, no UI frames, no labels.

System rules: medal shape is determined by category; edge material and glow are determined by rarity; center illustration is determined by the specific achievement. Rarity edges: Common = warm worn silver edge, Rare = blue arcane edge, Fine = green emerald edge, Epic = violet runic edge, Legendary = gold-orange radiant edge. Category shapes: Account = round seal, Check-in = calendar shield, Community Post = hex crest, Guild = heraldic shield, Market Item = diamond badge, Social Reputation = heart crest, Story Archive = scroll-edged octagon, Character Profile = vertical oval, Sponsor = crown silhouette, Level = star crest.

Lighting: upper-left soft key light, subtle rim glow matching rarity, polished bevels, carved enamel center, slight ambient shadow inside each medal only. Make all icons cohesive and from the same visual system.
